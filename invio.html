Come inviare la fattura XML

Hai generato il tuo file XML con BrioFE? Scopri come trasmetterlo al Sistema di Interscambio (SDI) tramite PEC o piattaforma Agenzia Entrate.

Vedi i metodi
Metodi di trasmissione

Scegli il modo che preferisci

Esistono due canali principali per trasmettere la fattura elettronica al Sistema di Interscambio (SDI). Entrambi sono ufficiali e conformi alla normativa.

📧

Invio via PEC

Trasmissione mediante Posta Elettronica Certificata direttamente all'indirizzo SDI.

✓ Vantaggi:
• Semplicissimo e immediato
• Nessuna registrazione necessaria
• Ricevi ricevuta di consegna garantita
⚠ Limitazioni:
• Necessaria una casella PEC attiva
• Un solo file per email
🏛️

Piattaforma Agenzia Entrate

Upload diretto tramite "Fatture e Corrispettivi" nel portale dell'Agenzia Entrate.

✓ Vantaggi:
• Nessuna PEC richiesta
• Upload multiplo di file
• Storico e tracciamento completo
⚠ Limitazioni:
• Registrazione e autenticazione richieste
• Interfaccia più articolata

📧 Metodo 1: Invio via PEC

1

Preparazione del file

Scarica il file XML generato da BrioFE. Il file avrà un nome simile a IT12345678901_FPR12_BFXXYYY.xml.

Verifica importante: assicurati che il file sia in formato XML e non compresso (.zip).

2

Apri il tuo client di posta certificata

Utilizza il software fornito dal tuo provider di PEC (Legalmail, Postemail, Aruba, ecc.) oppure accedi via webmail al portale della tua casella PEC.

💡 Info: Se non hai una casella PEC, contatta il tuo provider di posta certificata. Le principali sono Aruba PEC, Postemail, Legalmail e altri certificati dall'AGID.
3

Componi il nuovo messaggio

Crea una nuova email certificata e:

  • Destinatario: sdi01@pec.fatturapa.it
  • Oggetto: puoi lasciare vuoto o scrivere un descrizione (es. "Invio fattura n. 123")
  • Corpo: non è necessario scrivere nulla (puoi lasciare il messaggio vuoto)

4

Allega il file XML

Clicca su "Allega file" o "Aggiungi allegato" e seleziona il file XML scaricato da BrioFE.

⚠️ Importante: Puoi allegare un solo file XML per messaggio PEC. Se devi inviare più fatture, invia un messaggio per ognuna.
5

Invia la PEC

Clicca il pulsante "Invia" e attendi la conferma di trasmissione. La PEC ti fornirà automaticamente una ricevuta di avvenuta consegna (Delivery Status Notification, DSN).

✓ Confermato: Quando ricevi la ricevuta di consegna, significa che il file è arrivato correttamente presso il Sistema di Interscambio (SDI).
6

Ricevi il risultato

Entro pochi minuti riceverai una nuova email dal Sistema di Interscambio con il risultato dell'elaborazione:

  • ✓ Esito positivo: La fattura è stata accettata e trasmessa al destinatario
  • ⚠️ Esito negativo: Errori di validazione (correggi il file e reinvia)

🏛️ Metodo 2: Piattaforma "Fatture e Corrispettivi"

1

Accedi al portale Agenzia Entrate

Visita il sito ufficiale www.fatturapa.gov.it e clicca su "Accedi" o "Entra in Fatture e Corrispettivi".

2

Effettua l'autenticazione

Accedi con una delle seguenti credenziali:

  • SPID (Sistema Pubblico di Identità Digitale): la soluzione più rapida e moderna
  • CIE (Carta d'Identità Elettronica): con lettore smartcard
  • CNS (Carta Nazionale dei Servizi): per professionisti e imprese
  • Credenziali Agenzia Entrate: username e password del tuo conto
💡 Consiglio: Se non hai ancora SPID, registrati gratuitamente su uno dei provider ufficiali (Poste ID, Aruba ID, Tim ID, ecc.).
3

Accedi alla sezione upload

Una volta autenticato, seleziona la sezione "Comunicazioni" o "Invia fattura" dalla homepage o dal menu laterale.

4

Scegli il tipo di caricamento

La piattaforma ti oferirà diverse opzioni:

  • "Carica file XML": scegli questa opzione per il tuo file XML da BrioFE
  • Sono supportati anche file .zip contenenti più fatture XML

5

Seleziona e carica il file

Clicca su "Sfoglia" o "Seleziona file" e scegli il file XML scaricato da BrioFE. Puoi caricare uno o più file contemporaneamente.

✓ Multi-upload: Questa è una della differenza principali con la PEC: puoi inviare più fatture in una sola volta selezionando più file.
6

Avvia la trasmissione

Clicca il pulsante "Invia" o "Trasmetti". La piattaforma inizierà l'elaborazione dei file.

7

Monitora lo stato

Visualizzerai uno storico degli invii con i relativi stati:

  • ⏳ In elaborazione: il file è in corso di verifica
  • ✓ Accettato: la fattura è corretta e stata trasmessa al destinatario
  • ⚠️ Errore: ci sono problemi di validazione (verifica il messaggio di errore)
📊 Storico: Potrai sempre visualizzare lo storico completo delle trasmissioni, con date, orari e risultati.
Informazioni utili

Risorse e contatti

📖 Normativa

La fatturazione elettronica è regolata dal Decreto Legge 127/2015 convertito in Legge 124/2015 e successive modifiche. Consulta le linee guida ufficiali dell'Agenzia delle Entrate.

🔗 Link ufficiali

Portale Fatture e Corrispettivi:
www.fatturapa.gov.it

SDI Info:
www.agenziaentrate.gov.it

❌ Cosa fare in caso di errore

Se ricevi un errore di validazione, controlla il messaggio di errore dalla Agenzia Entrate, correggi il file in BrioFE e reinvia.

Fattura elaborata? Perfetto!

Hai generato il file XML e l'hai inviato. Ora puoi tracciare lo stato della fattura nel portale Agenzia Entrate e ricevere la conferma di consegna al cliente.
